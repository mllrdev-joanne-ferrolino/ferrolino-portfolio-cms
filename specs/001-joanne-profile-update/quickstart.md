# Quickstart

## Update Joanne profile content

1. Edit `content/index.yml` for hero title/description, social links, resume CTA, and experience summary.
2. Edit `content/about.yml` for the long-form bio and about images.
3. Update global defaults in `app/app.config.ts` if needed (email, meeting link, footer socials).

## Preview locally

- `pnpm dev`

## Validate content

- `pnpm lint`
- `pnpm typecheck`
- `pnpm build`
